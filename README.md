  <h1>Матричый тренажёр</h1>
</div>

Это университетский проект, нацеленный на создание инструмента для тренировки навыков работы с матрицами и операциями над ними (определители, решение СЛАУ и т.д.)

## Установка и запуск
```bash
pip install -r requirements.txt
python main.py
```
